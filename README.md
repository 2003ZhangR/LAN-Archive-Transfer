# LAN Archive Transfer

用于局域网课堂的作业提交工具，提供教师端和学生端 GUI。教师集中管理学生账号并接收作业，学生使用学号和密码登录、修改密码，在知悉并启用课堂监控后提交 ZIP / RAR 压缩包。

## 功能

- **教师端**：创建学生账号、CSV 批量导入、搜索账号、重置密码、选择保存目录、开启和停止接收、查看接收记录。
- **学生端**：账号密码登录、自行修改密码、确认并启用监控、选择压缩包、查看上传进度与提交结果。
- **作业接收**：按学号归档，支持并发上传、失败重试和 SHA256 完整性校验；同一学号下的同名文件在新文件接收并校验成功后覆盖。
- **课堂监控**：记录前台软件使用情况、操作次数、浏览器与 USB 存储设备告警，保留同一学号的历次监控会话，并随作业提交日志。

## 环境与安装

学生端监控依赖 Windows，建议教师端和学生端均在 Windows 10 / 11 上运行。当前开发环境为 Python 3.14，GUI 使用 PySide6。

在项目目录打开 PowerShell，执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

教师与学生电脑都需要安装依赖，并连接到能够互相访问的同一局域网。接收端口固定为 TCP `9000`；首次运行教师端时，Windows 防火墙若提示，请允许专用网络访问。

## 教师端使用

双击 [启动教师端.cmd](启动教师端.cmd)，或执行：

```powershell
.\.venv\Scripts\python.exe teacher_client.py
```

1. 输入学号和姓名（可选），点击“创建账号”；也可以点击“导入 CSV…”批量创建。
2. 创建账号的初始密码统一为 **`12345678`**。
3. 选择作业保存目录，点击“开始接收”。
4. 将界面显示的教师电脑 IPv4 地址告知学生，并保持窗口运行。
5. 学生忘记密码时，搜索并选中账号，点击“重置选中账号密码为 12345678”。
6. 点击“停止接收”或关闭窗口可以停止服务，已保存的账号和作业继续保留。

教师 GUI 与命令行接收服务使用同一端口，同一电脑上只启动其中一个。

需要自定义数据库或保存目录时：

```powershell
.\.venv\Scripts\python.exe teacher_client.py --accounts-db ".\teacher_data\students.sqlite3" --save-dir "D:\课堂作业"
```

### CSV 批量导入

使用 [学生账号导入模板.csv](学生账号导入模板.csv)，或在教师端点击“保存 CSV 模板…”。文件需使用 UTF-8 编码，支持 UTF-8 BOM。

```csv
学号,姓名
20260001,张三
20260002,李四
```

- 学号为必填列，姓名可留空或省略；也支持英文列名 `student_account,name`。
- 学号支持 1–32 位数字、英文字母、下划线和短横线，不能使用 Windows 保留名称。
- Excel 中含前导零的学号应设为文本，避免导出 CSV 时丢失前导零。
- 新导入账号的密码统一为 `12345678`，无需提供密码列。
- 已有学号和文件内重复学号会跳过，不覆盖原有姓名或密码。
- 空学号行会跳过；若存在格式无效的学号，导入会报出行号，本次不会新增账号。

## 学生端使用

双击 [启动学生端.cmd](启动学生端.cmd)，或执行：

```powershell
.\.venv\Scripts\python.exe student_client.py
```

1. 填写教师电脑 IP、自己的学号和密码，点击“进入学生端”。账号须由教师事先创建，教师端须已开始接收。
2. 阅读课堂监控范围，勾选知情同意，点击“确认并启用监控”。
3. 点击“选择文件…”，选择已经压缩好的 `.zip` 或 `.rar` 作业包。
4. 点击“上传作业”，等待文件与监控日志提交完成；界面显示“作业提交成功”后即完成提交。
5. 退出登录或关闭程序时，监控会停止并保存日志。

也可以通过参数预填教师 IP：

```powershell
.\.venv\Scripts\python.exe student_client.py --ip 192.168.1.20
```

### 修改密码与忘记密码

- **自行修改**：登录后点击“修改密码”，填写旧密码、新密码和确认新密码，成功后使用新密码重新登录。
- **忘记密码**：联系教师在教师端重置，重置后的密码固定为 `12345678`。
- 修改或重置密码后，原登录会话失效，需要重新登录。新密码不能为空，长度不超过 128 个字符。

### 监控范围

监控由学生阅读说明并明确同意后启用，GUI 中须在监控运行时才能选择和上传作业。

记录内容包括登录时间、电脑名称、系统版本、学生电脑 IP、前台软件名称与使用时长、按键和鼠标事件次数，以及浏览器使用和 USB 存储设备连接告警。

不记录具体按键内容、窗口标题、网址、网页正文或 U 盘文件。再次启用监控会追加新的会话，保留已有历史记录。

## 数据与文件结构

```text
LAN Archive Transfer/
├── teacher_client.py           # 教师端 GUI
├── student_client.py           # 学生端 GUI
├── accounts.py                 # SQLite 账号管理与认证
├── upload.py                   # 作业传输与接收服务
├── monitoring.py               # Windows 课堂监控
├── 启动教师端.cmd
├── 启动学生端.cmd
├── 学生账号导入模板.csv
├── requirements.txt
├── README.md
├── teacher_data/               # 教师运行后生成的账号库
├── 接收作业/                    # 默认作业保存目录
└── student_status/             # 学生运行后生成的监控日志
```

教师账号库默认位于 `teacher_data/students.sqlite3`，存储学号、姓名和加盐 PBKDF2-SHA256 密码哈希。学生通过教师端服务验证密码，不直接访问数据库。该目录只保存在教师电脑，不随代码分发给学生；迁移教师数据时应一并备份账号库和作业目录。

默认接收结果：

```text
接收作业/
└── 20260001/
    ├── Python作业.zip
    └── .programming-status-20260001.json
```

学生本地日志位于 `student_status/.programming-status-学号.json`。账号库、作业、监控日志、虚拟环境和 Python 缓存均已通过 `.gitignore` 排除，不提交到 Git。

## 命令行使用

以下命令在已安装依赖的 Python 环境中执行；使用本项目虚拟环境时，将 `python` 替换为 `.\.venv\Scripts\python.exe`。

### 教师账号管理

```powershell
# 创建账号，默认密码 12345678
python accounts.py add --student-account 20260001 --name "张三"

# 批量导入
python accounts.py import --file ".\学生账号导入模板.csv"

# 查看账号
python accounts.py list

# 重置密码为 12345678
python accounts.py reset --student-account 20260001
```

指定账号库时，`--db` 放在子命令前，例如 `python accounts.py --db "D:\教师数据\students.sqlite3" list`。

### 接收与上传

```powershell
# 教师启动接收，按 Ctrl+C 停止
python upload.py receive --save-dir ".\接收作业"

# 学生上传，运行后提示输入账号密码
python upload.py send --ip 192.168.1.20 --student-account 20260001 --file "D:\作业\Python作业.zip"
```

`send` 自动附带该学号已有的本地监控日志，也可以通过 `--status-file` 指定。命令行上传不会自动启动监控，需要完整课堂流程时使用学生 GUI。

### 独立监控

```powershell
python monitoring.py --student-account 20260001 --ip 192.168.1.20
```

程序显示采集范围，输入“同意”后开始；按 Ctrl+C 停止并保存日志。

## 通信方式

教师端使用局域网 HTTP 服务，端口固定为 `9000`。学生账号密码验证成功后取得登录令牌，作业上传、状态查询、监控日志提交和密码修改接口均校验登录身份。当前通信未启用 HTTPS，适用于能够互相访问的课堂局域网。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 提示找不到 PySide6 | 使用启动脚本或项目虚拟环境运行，并安装 `requirements.txt` 中的依赖。 |
| 学生无法连接教师端 | 确认教师已点击“开始接收”、IP 正确、网络互通，且防火墙允许 TCP 9000。 |
| 教师端提示端口占用 | 关闭已有教师端或命令行接收服务，再启动一个接收服务。 |
| 账号或密码错误 | 请教师确认学号已创建，或将密码重置为 `12345678`；修改密码后应使用新密码。 |
| 无法选择或上传作业 | 在学生端勾选知情同意并成功启用监控，再选择有效的 ZIP / RAR 文件。 |
| CSV 导入失败 | 使用 UTF-8 编码，确认包含“学号”列，按报错行号检查学号格式。 |
